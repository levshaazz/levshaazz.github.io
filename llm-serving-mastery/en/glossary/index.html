Glossary

Course-local definitions. Each term links back to the topic where its measurement contract is introduced.

Quantization scale T03
Reconstruction step or scale factor. In an affine integer toy it has weight-value units per code; q = clip(round(w/s) + z), reconstructed w = s(q − z).
Zero point T03
Integer code that represents zero in an affine quantizer. It is a representation parameter, not the floating-point scale or a model bias.
Nibble T03
Four bits. Two INT4 codes can share one byte, but nibble order, signed encoding, padding and logical tensor shape must be specified.
NF4 T03
NormalFloat4: sixteen nonuniform reconstruction levels, used with block scales in the lab. Four bits do not imply the same codebook, packing or kernel as signed INT4.
Paired discordance T03
Prompt-level outcomes on which two candidates disagree. Equal aggregate success rates can hide different regressions and gains.
SSE data event T04
Data dispatched after a blank line. One network read can contain many events or part of one; an event can contain several tokens or no text.
Finish reason T04
Application field explaining why generation ended. It is distinct from the terminal DONE marker, connection EOF and validation of the answer's usefulness.
Incremental UTF-8 decoding T04
Decoding that retains incomplete multibyte characters across byte reads, so splitting a character at a transport boundary does not corrupt its text.
Residual stream T02
The hidden vector carried at each position. Attention and MLP branches add updates to it; the retained KV cache is separate state.
RMSNorm T02
Per-position normalization using the root mean square over hidden features, epsilon and a learned feature scale. It does not mix sequence positions or subtract their mean.
RoPE T02
Rotary positional embedding: position-dependent rotations of paired query/key coordinates. In this Qwen implementation values are not rotated.
SwiGLU T02
A gated feed-forward branch: apply SiLU to the gate projection, multiply elementwise by a separate up projection, then project down to the residual width.
Logits T02
Unnormalized vocabulary scores. Greedy decoding selects their largest entry; softmax probabilities are not a measure of factual confidence.
Admission control T01
Decision to accept, queue, shed, or defer a request before it consumes scarce serving capacity.
Arithmetic intensity T02
Operations performed per byte moved at the memory level being modeled.
Continuous batching T01
Scheduler that can change the active request batch between decode iterations.
Decode T01
Autoregressive phase that produces new tokens one iteration at a time using cached keys and values.
Failure rate T00
Failed requests divided by all attempted requests under the declared workload and timeout.
GQA T02
Grouped-query attention: multiple query heads share fewer key/value heads.
ITL T00
Inter-token latency: time between two consecutive streamed output tokens for one request.
KV cache T02
Per-request key/value state retained from earlier tokens to avoid recomputing attention history.
Little’s Law T01
For a stable system, average concurrency equals arrival rate times average time in system: L=λW.
Operational intensity T02
Measured operations per byte at a chosen boundary; used to place work on a roofline chart.
Quantization T03
Mapping high-precision values into a lower-bit representation with a reconstruction rule, metadata and error.
AWQ T03
Activation-aware weight quantization: uses activation statistics to protect salient channels through scaling.
GPTQ T03
Post-training weight quantization that uses approximate second-order information to compensate quantization error.
Served model name T04
The API-facing model identifier advertised by /v1/models and sent in the client's model field.
SSE T04
Server-sent events: UTF-8 event framing over HTTP. The vLLM chat application adds JSON deltas and a DONE marker; these are not universal SSE protocol fields.
Prefill T01
Parallel processing of prompt tokens that builds initial KV state and produces the first-token logits.
Roofline T02
Upper-bound performance model combining compute and bandwidth ceilings; not a full latency predictor.
SLO T01
Service-level objective: a measurable reliability or performance target over a defined population and window.
Tail latency T00
A high percentile such as p95 or p99, always meaningful only with its population and failure semantics.
TPOT T00
Time per output token after the first, usually decode duration divided by post-first-token gaps; not one individual ITL.
TTFT T00
Time from the declared request start boundary until the first output token becomes observable.
CUDA event interval T02
Elapsed time between device events on a stream; may include launch gaps and is not a sum of kernel durations.
Allocated vs reserved memory T02
Allocated memory holds live tensors; reserved memory also includes blocks retained by the caching allocator. Neither is total device usage.
Kernel interval union T02
Total time covered by at least one recorded physical kernel interval, counting overlaps once. It excludes other unrecorded activity.
Warmup T02
Unreported execution of the actual shape/path before timed trials; not permission to discard slow measured repeats.
Clipping T03
Mapping a value outside the representable range to an endpoint; distinguish it from rounding within the range.
