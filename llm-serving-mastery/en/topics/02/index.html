Learning outcomes

  1. Predict how prefill and decode stress a GPU differently.
  2. Derive KV-cache bytes/token from a pinned model config.
  3. Use synchronized timing and select the right profiler layer.
  4. Reconcile a hand calculation with measured evidence.

Acceptance checklist

  • Both model revisions are immutable commits.
  • Load, warm-up, prefill, and decode are distinct regions.
  • CUDA timing is synchronized.
  • Allocated, reserved, peak, and device-total memory are not conflated.
  • Profiler overhead is not presented as production latency.
