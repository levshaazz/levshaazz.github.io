vLLM tuning: moving the curve

Four knobs (max-num-seqs, gpu-memory-utilization, max-model-len, chunked prefill), a predeclared bounded search, a Pareto front between speed and tail, and one frozen production profile validated on held-out texts.

Learning outcomes

  1. Map each vLLM knob to the mechanism it controls and predict the curve effect before measuring.
  2. Design a bounded, predeclared search with an explicit run budget.
  3. Execute the search and build an honest config-to-curve table where failures are rows.
  4. Find the Pareto front and choose one profile under an SLO with a falsifiable rationale.
  5. Freeze the profile with a forecast and validate on a distinct held-out load.
  6. Stretch: name the edge risk and write a rollback plan.
