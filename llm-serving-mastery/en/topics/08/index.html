Production inference APIs: FastAPI + vLLM

One thin FastAPI gateway in front of the frozen engine: request validation with hard caps, request identity, bounded-queue admission with honest 429s, client-disconnect cancellation, an error map that never returns 200-with-error-body, one structured output, and /metrics counters — the whole contract exercisable on free CPU against a declared mock engine.

Learning outcomes

  1. Map each API mechanism to the serving mechanism it wraps and predict gateway behavior before building.
  2. Implement bounded-queue admission with 429 backpressure and justify the queue cap with Little's law.
  3. Cancel on client disconnect and prove no orphaned generation continues, with wasted tokens counted.
  4. Map engine outcomes to honest HTTP codes and trigger two failure modes on demand.
  5. Serve one schema-constrained completion and validate the reply, including the violation path.
  6. Load the gateway with the course wave driver and defend the gateway SLO in a short memo.
