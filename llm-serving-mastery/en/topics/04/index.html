Learning outcomes

  1. Verify the served identity and implement an admission guard using rendered tokens and an output cap.
  2. Explain token selection and evaluate complete, valid and correct predictions with a 3x4 confusion matrix over all attempts.
  3. Freeze output cap and format policy, run a bounded vLLM smoke plus calibration/held-out task probes and diagnose actual errors.

Student work sequence

  1. A: identity and your rendered-context guard
  2. B: token selection and your all-attempt scoring
  3. C: actual Qwen errors, confusion matrix and sampling intervention
  4. D: frozen cap/format, fresh task probe and engineering memo

Expected workload · 2 hours contact + 12–16 hours guided work

Acceptance checklist

  • Implement the rendered-token admission guard; all 11 CPU checks pass.
  • Implement all-attempt classifier scoring; six fixtures check rates and the 3x4 confusion matrix.
  • Change temperature/top_p in the numerical toy; distinguish next-token probability from class confidence.
  • Inspect actual Qwen FP16 errors and explain the measured confusion matrix.
  • Declare one-factor candidates, compare fresh calibration results, then freeze a chosen policy before loading held-out.
  • Save CPU work, fresh GPU evidence and a boundary-aware engineering memo separately.
