Model quantization for production

Follow actual values through rounding, packing, reconstruction and output error, then compare literal prompts on pinned FP16/NF4 candidates with explicit memory and timing limits.

Learning outcomes

  1. Calculate nearest-even rounding, clipping, packed INT4 bytes, reconstruction and input-dependent output error.
  2. Distinguish W4A16, W8A8, FP8, NVFP4 and KV format choices.
  3. Explain AWQ and GPTQ without equating them to the NF4 lab.
  4. Select a deployment candidate using measured fit, quality and latency.

Acceptance checklist

  • FP16 and NF4 use the same pinned model/tokenizer, device, prompts and output cap.
  • Payload arithmetic is not misreported as process memory.
  • The tiny smoke set is not called a representative quality benchmark.
  • Kernel support and fallback are checked on the actual device.
  • Natural-EOS quality samples are separate from four prompts × three fixed-length timing trials per format.
  • Three-trial nearest-rank p95 is just the observed maximum, not a stable production tail estimate.
  • The CPU validator rejects partial or inconsistent artifacts; it cannot prove measurement authenticity.
  • Raw trials, invalid outputs and a conditional go/no-go decision are preserved.

Open the primary sources

  • bitsandbytes 0.50.2 · NF4 codebook and quantization functions — The actual nonuniform lookup values in the pinned lab runtime. The course signed-INT4 packing example is a separate invented format, not an implementation of these CUDA kernels.
  • Pinned Qwen2.5-0.5B-Instruct configuration — Pinned model dimensions for the teaching notebooks; use the recorded runtime and actual selected attention path.
  • GPTQ — Second-order post-training weight quantization; distinct from the NF4 teaching lab.
  • AWQ — Activation-aware weight quantization; not a generic name for all four-bit paths.
  • vLLM quantization support — Version- and hardware-sensitive format support; verify the installed release.
  • PyTorch 2.14 · CUDA execution and memory — Asynchronous execution, synchronization and the caching allocator. Allocated, reserved and whole-device memory are different quantities.
