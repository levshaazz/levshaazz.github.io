The Saturation Knee

High concurrency: the saturation knee

Waves of 8/32/64/128 closed-loop clients, journals where errors are data, an operational knee definition and one defended operating point; a measured T4 run and an interference stretch with a frozen cap.

Learning outcomes

  1. Compute a KV budget and freeze a falsifiable knee prediction before measuring.
  2. Run controlled waves with a terminal-outcome journal and audit it before analysis.
  3. Build error-aware curves, locate the knee by a declared gain rule and defend one operating point under an SLO.
  4. Stretch: measure A/B interference and freeze an in-flight cap before a held-out pair.
