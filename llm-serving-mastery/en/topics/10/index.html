Multi-GPU inference: tensor parallelism

One GPU ends twice: memory and step floor. Tensor parallelism splits weight matrices exactly (column/row-parallel with all-reduce joins), pays a named sync beat per block, moves the knee of the step-time curve and itemises the per-GPU memory ledger. The lab is a declared CPU simulation with a real NumPy split proof; the multi-GPU vLLM route is an owner demonstration.

Learning outcomes

  1. Explain tensor-parallel mechanics (column/row splits, all-reduce) and prove split equals full within fp tolerance.
  2. Build the declared step-time model and predict the knee degree before any sweep.
  3. Run the TP-degree sweep and give an honest verdict against the frozen plan, naming the mechanism.
  4. Itemise the per-GPU memory ledger and decide the minimal fitting TP degree.
  5. Diagnose comm-bound and straggler failures from transcripts with cause, evidence and fix.
  6. Place TP among PP/DP/EP and write the vLLM tensor_parallel_size card with its interconnect precondition.
