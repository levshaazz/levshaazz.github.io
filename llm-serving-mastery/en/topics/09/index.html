Topic 09 · Published

Docker for LLM inference

The Topic 08 gateway becomes an immutable image: ordered layers as cache policy, a lean pinned multi-stage build, the same API contract probed across the container boundary, cold/warm startup economics measured on the student's own machine, deliberate failure drills (tag drift, memory-limit OOM), and an SBOM-backed supply-chain look. CPU images for everyone; the CUDA/vLLM variant is an owner demonstration.

Learning outcomes

  1. Explain image = ordered layers and predict which edits invalidate the build cache.
  2. Write a lean, pinned, non-root image and itemize its layer sizes.
  3. Probe the full API contract across the host-container boundary.
  4. Measure cold vs warm startup and cut the dominant term with one justified change.
  5. Diagnose tag drift and memory-limit OOM from logs and exit codes.
  6. Produce an SBOM and name the supply-chain risks it exposes.
