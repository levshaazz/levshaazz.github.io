05 · Quantization and clipping

Signed integer quantization with zero point 0: round x / scale to nearest, ties to even, clip to the integer range, then reconstruct code × scale. Scale has input-value units per code. This teaching rule is not NF4, AWQ or a complete model-quality test.

Try → explain → check. With 4 bits and scale 0.25, x=1.17 reconstructs as 1.25 (error 0.08). Set x=2.25: the maximum code is 7, so it clips to 1.75 (error 0.50). Increase scale to 0.50 and explain the rounding/clipping trade-off.

One scalar cannot establish end-to-end quality or kernel acceleration. Chapter 03 · Paired FP16/NF4 lab.
