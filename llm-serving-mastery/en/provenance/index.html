Provenance and evidence policy

How to decide whether a course claim, benchmark, or published artifact is canonical.

Content source
Repository files on the deployed commit are canonical; generated docs/ output is not edited directly.
Deployment
The public Pages host polls private main every 30 minutes, runs course checks and a build, then publishes only the generated student-facing site.
Judge
Judge contract v5; Round 01 uses a verified RTX 5070 Ti reference and completed five-case shadow round. One submission has a 90-minute whole-run budget and one shared 45-minute startup budget.
Measured evidence
Reference numbers require raw request records, environment and revision metadata, metric-contract version, and an operator note.
Known gap
Topic 00 demo numbers are validated only for the recorded Tesla T4, pinned model/runtime, simultaneous-wave workload, and successful-output goodput semantics. Topics 01–04 instructor lab measurements are bounded single-host teaching evidence, not production quality or judge throughput claims. Topics 05–15 remain planned.

Reviewed instructor evidence

Topic 00's concurrency demonstration and Topics 01–04's bounded GPU labs are separate experiments. The lab rehearsal is not a judge reference or a production quality/throughput benchmark. Read each operator note before comparing numbers.
