The measured matrix is inside a gated MLP

Pinned Qwen MLP architecture
Trace both branches with a finger. Gate and up use different learned matrices on the same normalized hidden state. SiLU is applied only to gate before the elementwise product. We hook the product entering down, not an arbitrary hidden-state tensor.

Know which dimension you quantize

One down projection · no bias
$$Y=XW^\top,\qquad Y_{t,o}=\sum_{i=0}^{4863}X_{t,i}W_{o,i}$$
X[T, 4864]MLP inputs; T token positions after flattening batch
W[896, 4864]PyTorch weight: output rows, input columns
Y[T, 896]Layer output; not the vocabulary distribution
896 × 4864 = 4,358,144 weights. One row computes one output feature.
A group is consecutive input columns within a row; group 64 gives 76 groups per row.
Use one output coordinate to explain the sum. T is the total number of recorded positions, not the vocabulary size. Activation values and weights are dimensionless learned quantities. The model takes [1,S,4864] into this layer; we flatten positions only for analysis. A channel here means a feature index, not a token.

AWQ: equivalent channel rescaling

Worked CPU arithmetic · not model measurements
$$W'=WD,\quad X'=XD^{-1},\quad X'(W')^\top=XW^\top$$
D[in,in] diagonalOne multiplier per input feature
X, W[samples,in], [out,in]Divide inputs; multiply columns
Multiply weight .49 by 2; divide its input feature by 2.
Exact before rounding; not afterwards. AWQ §3.2.
AWQ uses activation information and searches channel scales. This is its equivalent-transformation mechanism, not mixed-precision preservation of a few weights. D is not the scalar quantizer step.

Protect an active input channel, not the largest weight

Illustrative mechanism · not full AWQ/GPTQ
Before rounding, multiplying the weight column and inversely scaling the input exactly preserves the function. Distinguish large activations from large weight magnitudes. Follow the same feature in both operands.

GPTQ: choose the compensation from inputs

Worked CPU arithmetic · not model measurements
$$a=\frac{(.49-0)\sum_n X_{n0}X_{n1}}{\sum_n X_{n1}^{2}}=\frac{.49}{2}=.245$$
aweight correctionAdjust the unrounded second weight
n2 calibration samplesCorrelation 1; energy 2
.40 + .245 = .645 → round to 1. Final codes: [0,1].
Minimizes (−.49 + a)² + a² before the next rounding. GPTQ §§3–4.
This one-remaining-coordinate least-squares update explains compensation. Full GPTQ uses inverse-Hessian information, damping, Cholesky and blocks. Those implementation details are optional; the mechanism is mandatory.

W4A16 separates storage from arithmetic

Illustrative execution path · actual kernel must be observed
Packed four-bit weights and scales enter unpacking and dequantization. Reconstructed weights multiply sixteen-bit activations and accumulate in the kernel’s declared type. Dequantization may fuse inside a kernel or write a temporary buffer.
