The measured matrix is inside a gated MLP

Pinned Qwen MLP architecture
Trace both branches with a finger. Gate and up use different learned matrices on the same normalized hidden state. SiLU is applied only to gate before the elementwise product. We hook the product entering down, not an arbitrary hidden-state tensor.

Know which dimension you quantize

One down projection · no bias
$$Y=XW^\top,\qquad Y_{t,o}=\sum_{i=0}^{4863}X_{t,i}W_{o,i}$$
X[T, 4864]MLP inputs; T token positions after flattening batch
W[896, 4864]PyTorch weight: output rows, input columns
Y[T, 896]Layer output; not the vocabulary distribution
896 × 4864 = 4,358,144 weights. One row computes one output feature.
A group is consecutive input columns within a row; group 64 gives 76 groups per row.
Use one output coordinate to explain the sum. T is the total number of recorded positions, not the vocabulary size. Activation values and weights are dimensionless learned quantities. The model takes [1,S,4864] into this layer; we flatten positions only for analysis. A channel here means a feature index, not a token.

Derive seven positive steps rather than handing students an unexplained scale. The maximum absolute weight is the negative extreme, not the largest positive value. Ties-to-even is explicit. The input determines how weight error propagates

Same inputs · matching output coordinates
$$\Delta Y=X(\widehat W-W)^\top,\qquad r=\frac{\lVert\Delta Y\rVert_F}{\lVert XW^\top\rVert_F}$$
\(\widehat W-W\)[896, 4864]Weight error; reused for every input position
\(\Delta Y\)[T, 896]Output error, weighted and mixed by actual X
rdimensionless ratioFrobenius norm over every recorded output
Held-out set: X is [121,4864], Y is [121,896]. Group 64 gives r ≈ 0.1094.
10.94% relative layer-output error is not 10.94% task error or accuracy loss.
Expand one output coordinate. A large activation can amplify error on its corresponding input column; correlations can make errors add or cancel. This motivates calibration and eventually the Hessian geometry in GPTQ. The norm aggregates all coordinates; it is not the mean of per-token relative errors, and it does not compare independently generated sequences.

Measure the output, not just the histogram

Measured Qwen · CPU FP32 / simulated INT4
Read one point: its x coordinate is one original layer output, and y is the matching reconstructed-weight output on exactly the same input. The diagonal is equality. Plotted points are deterministic, while the error metric uses all held-out outputs. Distinguish scalar output channels from vocabulary logits.

The two objectives weight errors differently through X. Even a small downstream logit change can flip close candidates, while large internal error need not flip a large-margin decision. Ask students to state what the experiment can establish. The next slide compares two grouped/ungrouped absmax settings, not these clipping thresholds; make that change of comparison explicit.

The same context can produce different probabilities

Measured Qwen · CPU FP32 / simulated INT4
The baseline itself predicts token 4 first for this prompt; it is not the correct next number in the sequence. Preserving a model distribution is not proving task correctness. Only one layer changes. The tensor intervention changes the argmax to The; group 64 keeps 4. Do not extrapolate to full-model quality.
