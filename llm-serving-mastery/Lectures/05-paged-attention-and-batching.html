Selected output IDs are not automatically cached positions

One ML serving investigation

Forward computation

Prefill computes KV for the input and predicts the first output ID. That ID enters KV when consumed by a later forward.

Capacity planning

Prompt plus output cap is a useful conservative position budget, not an exact instantaneous cache length.

Natural EOS can stop before the cap. A selected stop ID may never be consumed in another forward. Engine lookahead and allocation policy can reserve beyond current live positions.

Which request can take the released slot?

Placement · iteration · evidence

Autoregression remains sequential within one request even while independent requests share an iteration.

Batching does not remove autoregression

One ML serving investigation

Inside one request

The next input ID depends on the previous selected output. Five decode steps remain dependent.

Across requests

Independent sequences can contribute work to the same iteration. Finishing one need not hold all others.

Continuous batching changes the membership at boundaries. It is not parallel prediction of every future token in one request.
