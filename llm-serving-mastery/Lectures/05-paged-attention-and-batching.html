Forward computationПрямой проход

Prefill computes KV for the input and predicts the first output ID. That ID enters KV when consumed by a later forward.

Prefill считает KV для входа и предсказывает первый ID на выходе. Этот ID попадает в KV, когда его потребит следующий forward.

Capacity planningПланирование ёмкости

Prompt plus output cap is a useful conservative position budget, not an exact instantaneous cache length.

Промпт плюс потолок выхода — полезный консервативный бюджет позиций, а не точная мгновенная длина кэша.
