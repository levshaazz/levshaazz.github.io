Скачивания

Все опубликованные скачивания в одном месте. Лидерборд даёт те же файлы рядом с таблицами, к которым они относятся.

Учебный рантайм

  • Учебный рантайм (ZIP) — шлюз + пинованный llama.cpp (Лаба 09, секции Layer 2)
  • Рантайм тетрадей v1 (исторический, семинарский трек)

Labs 01–08, 10–12 and 15 run entirely in your browser; the runtime is needed by Lab 09 and the Layer-2 sections (Docker Desktop, ~2 GB). Unzip and run `docker compose up -d` — the portal finds it automatically.

Рантайм Google Colab (опционально)

  • Ноутбук-компаньон Colab (.ipynb) — одна ячейка настройки поднимает удалённый рантайм для любой лабы (URL и токен — в панель лабы)

Запустите ячейку настройки в своём Colab, вставьте напечатанные URL и токен в панель «Удалённый рантайм» лабы — тяжёлый код исполняется на ВАШЕМ рантайме, а редактирование и валидация остаются на странице. Туннель эфемерен: новый запуск печатает новые значения. Только практика — никогда не evidence курса.
