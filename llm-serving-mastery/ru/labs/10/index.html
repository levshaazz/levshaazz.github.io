Контракт до кода

Заявленная учебная модель напечатана целиком; предскажи по ней до запуска. Код исполняется в настоящем CPython внутри песочницы твоего браузера — только практика, никогда не evidence курса.

Словарь: каждое слово — через то, что ты уже запускал

Мини-флот в docker compose ты уже поднимал. Каждое слово Kubernetes ниже — тот же механизм, но декларативный и под присмотром контроллеров; ставить ничего не нужно.

Заявленная модель

Предскажи, затем проверь

Пользуйся только заявленной моделью — номинальные числа. Впиши число, нажми «Проверить».

Код: реализуй, запусти, пройди тесты

Настоящий Python исполняется в твоём браузере. Видимые тесты проверяют основной путь; скрытые — краевые случаи (скрытый тест показывает, какой упал, но не ответ). Лимит времени — несколько секунд: бесконечный цикл будет остановлен, а не заморожен.

Челлендж ★ — открытая цель без тестов

Здесь нет тестов-каркаса: открытая цель, путь к ней выбираешь сам, а страница проверяет результат, который ты произвёл, а не форму кода. Эталонное решение появится только после достижения цели. Челлендж живёт вне полосы прогресса — он для тех, кому мало.

Post-test: самопроверка

Вопросы на понимание в конце лабы — по памяти, без нового кода: неверные варианты отключаются, после верного ответа появляется объяснение. Карточки с меткой «мост» связывают лабу с более ранней темой.

Layer 2 · твой локальный движок

Удалённый рантайм · Google Colab (необязательно)

Тяжёлые вычисления можно исполнять на своём Colab-рантайме вместо песочницы браузера: код ты редактируешь здесь, страница отправляет его в рантайм, поднятый из ноутбука-компаньона, и валидирует результат ровно так же. Ничего не требуется — без рантайма всё работает в браузере.

Скачай ноутбук-компаньон, запусти его единственную ячейку настройки в Colab, скопируй напечатанные URL и токен, вставь сюда.

Твой код уходит в ТВОЙ рантайм; редактирование и валидация остаются на странице. Только практика — никогда не evidence курса. Не вставляй чужие адреса: рантайм исполняет тот код, который ты запускаешь.
