Результаты обучения

  1. Вывести масштабы и реализовать построчно-локальное групповое квантование; измерить ошибку выходов и затраты метаданных; объяснить масштабирование AWQ и компенсацию GPTQ.
  2. Выполнить зафиксированное сравнение FP16/NF4, меняя только фиксированную длину вывода с 24 на 96; сохранить сырые тайминги и естественные ответы на тикеты.
  3. Принять ограниченное решение keep/reject/inconclusive с одним прогнозом, сверенным с данными (подтверждён, пересмотрен или не разрешён), и одним различающим следующим экспериментом.

Последовательность студенческой работы

  1. Реализуем масштабы и построчно-локальные группы; сравниваем ошибки и метаданные
  2. Разбираем механизмы AWQ/GPTQ и представление NF4
  3. Выбираем по калибровке на реальном слое, замораживаем, затем проверяем на held-out
  4. Выполняем контролируемый A/B FP16/NF4 и сохраняем сырые данные
  5. Пишем ограниченное инженерное решение с ограничениями

Ожидаемая нагрузка · 2 contact hours plus an estimated 3–5 guided hours including preparation. Learner timing is unvalidated. Finish real-layer work before GPU execution; GPU analysis and memo may continue independently.

Открыть первоисточники

  • MIT EfficientML 2024 · teaching design — Adapted controlled changes and numerical simulation versus real storage; not the graduate workload or measured results.
  • CMU Deep Learning Systems · teaching design — Adapted progressive student implementation with executable tests, not solutions.
  • GPU Puzzles · teaching design — Adapted small executable exercises and transfer checks; no CUDA implementation required in this core.
  • bitsandbytes 0.50.2 · NF4 codebook and quantization functions — The actual nonuniform lookup values in the pinned lab runtime. The course signed-INT4 packing example is a separate invented format, not an implementation of these CUDA kernels.
  • Pinned Qwen2.5-0.5B-Instruct configuration — Pinned model dimensions for the teaching notebooks; use the recorded runtime and actual selected attention path.
  • GPTQ — Second-order post-training weight quantization; distinct from the NF4 teaching lab.
  • AWQ — Activation-aware weight quantization; not a generic name for all four-bit paths.
  • vLLM quantization support — Version- and hardware-sensitive format support; verify the installed release.
  • PyTorch 2.14 · CUDA execution and memory — Asynchronous execution, synchronization and the caching allocator. Allocated, reserved and whole-device memory are different quantities.
