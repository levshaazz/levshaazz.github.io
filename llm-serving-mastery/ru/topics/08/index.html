Продакшен-API инференса: FastAPI + vLLM

Один тонкий FastAPI-шлюз перед замороженным движком: валидация запросов с жёсткими лимитами, идентификация запросов, допуск через ограниченную очередь с честными 429, отмена при отключении клиента, карта ошибок, которая никогда не возвращает 200 с телом ошибки, один структурированный вывод и счётчики /metrics — весь контракт исполним на бесплатном CPU против объявленного mock-движка.

Результаты обучения

  1. Сопоставить каждый механизм API с механизмом serving, который он оборачивает, и предсказать поведение шлюза до сборки.
  2. Реализовать допуск через ограниченную очередь с backpressure по 429 и обосновать потолок очереди законом Литтла.
  3. Отменять генерацию при отключении клиента и доказать, что ни одна осиротевшая генерация не продолжается, с подсчётом потраченных впустую токенов.
  4. Отобразить исходы движка в честные HTTP-коды и вызвать два режима отказа по требованию.
  5. Обслужить одно завершение, ограниченное схемой, и провалидировать ответ, включая путь нарушения схемы.
  6. Нагрузить шлюз волновым драйвером курса и защитить SLO шлюза в короткой записке.

Требуемые артефакты

  • api-contract.json (замороженный прогноз)
  • журнал шлюза + доли по волнам
  • журнал отмен
  • снимок /metrics

Чек-лист приёмки

  • дизайн-аудит чист
  • преподавательский эталон: 0 ошибок на бесплатном CPU
  • дриллы перегрузки и отмены воспроизводят замороженный конверт
  • никакое mock-число не подаётся как измерение vLLM

Required reading

  • Официальная документация FastAPI (фоновые задачи, потоковые ответы)
  • Семантика HTTP: коды состояния, Retry-After, идемпотентность

Открыть первоисточники

  • RFC 9110 · HTTP semantics — Status-code contracts behind the gateway's honest error map: 400 validation, 429 throttling with Retry-After, 503 upstream failure.
  • FastAPI · documentation — The gateway framework taught in Topic 08: dependency wiring, request validation and async handlers over the frozen engine.
  • Uvicorn · documentation — The ASGI server that hosts the gateway: worker lifecycle and shutdown behavior behind graceful teardown.
  • vLLM · source repository — The upstream engine the mock declares and the production route pins; scheduler and API-server boundaries read from source.
