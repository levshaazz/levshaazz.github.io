Инференс на нескольких GPU: тензорный параллелизм

Одного GPU не хватает дважды: по памяти и по нижней границе времени шага. Тензорный параллелизм разрезает весовые матрицы точно (column/row-parallel со сборкой через all-reduce), платит названный такт синхронизации за каждый блок, двигает колено кривой времени шага и раскладывает ведомость памяти по каждому GPU. Лабораторная — объявленная CPU-симуляция с настоящим доказательством разреза на NumPy; маршрут multi-GPU vLLM — демонстрация владельца.

Результаты обучения

  1. Объяснить механику тензорного параллелизма (разрезы по столбцам/строкам, all-reduce) и доказать, что разрез равен полному matmul в пределах fp-допуска.
  2. Построить объявленную модель времени шага и предсказать колено по степени TP до всякого свипа.
  3. Выполнить свип по степеням TP и вынести честный вердикт против замороженного плана, назвав механизм.
  4. Разложить ведомость памяти по каждому GPU и выбрать минимальную подходящую степень TP.
  5. Диагностировать отказы comm-bound и straggler по транскриптам: причина, доказательство, исправление.
  6. Поставить TP среди PP/DP/EP и написать карточку tensor_parallel_size для vLLM с её предусловием по интерконнекту.

Требуемые артефакты

  • tp-plan.json (замороженный прогноз колена и подходящая степень)
  • split-proof.json (ошибки max-abs разреза против полного matmul)
  • sweep.json + sweep.png (кривая измеренное против чистой модели)
  • ledger.json + ledger.png (ведомость памяти по каждому GPU)
  • drills.json (два классифицированных транскрипта отказов)

Чек-лист приёмки

  • дизайн-аудит чист
  • преподавательский эталон: 17 кодовых ячеек, 0 ошибок на бесплатном CPU (пропусков по дизайну нет)
  • разрез равен полному matmul в пределах 1e-10 в журнале
  • вердикт называет механизм расхождения плана и свипа
  • все числа помечены как объявленная арифметика и никогда — как аппаратные измерения

Required reading

  • Статья Megatron-LM (arXiv 1909.08053): формулировка тензорного параллелизма
  • Документация vLLM: масштабирование параллелизма (tensor_parallel_size)
