Первый токен за 10 минут

Сначала ни одного слайда: к концу страницы настоящая модель на твоей машине отвечает тебе, токен за токеном. Всё локально, и твой прогресс не покидает этот браузер.

Твой прогресс онбординга

    файл прогресса сохранён

    События воронки живут только в твоём браузере (localStorage). «Поделиться прогрессом» отдаёт файл ТЕБЕ — курс их никогда не собирает. Только практика, никогда не evidence.

    Шаг 0 · Placement: восемь вопросов, один честный вердикт

    Без оценок и ставок — квиз выбирает твою стартовую глубину. Не знаешь — выбирай любой вариант: неверный ответ — это информация, а не позор.

    Шаг 1 · Окружение: два клика и две честные проверки

    Сначала вручную: Docker Desktop установлен, и docker compose up -d выполнен внутри папки runtime/ (ZIP — в Downloads). Затем страница сама пингует твой шлюз: здоровье движка и запиненные веса модели.

    Шаг 2 · Первый токен

    Один короткий промпт в твой настоящий движок, замер честный — на твоей машине. Смотри на номер журнала: эта запись в хэш-цепочке — твоя.

    Шаг 3 · Куда дальше

    Полная карта курса — в разделе «С чего начать»; практический путь — лабы. Полоса онбординга выше заполняется сама.
